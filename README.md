# Plan My Reunion plugin for Claude

This repository holds the Plan My Reunion plugin for Claude. The plugin is in the `plan-my-reunion` folder, and its README says what it does and what it connects to.

To install it in Claude Code:

```
/plugin install plan-my-reunion --marketplace planmyreunion/plan-my-reunion-plugin
```

Documentation: https://www.planmyreunionnow.com/assistant
